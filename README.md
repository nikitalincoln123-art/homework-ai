# ДомашкоБот — ИИ-помощник по домашним заданиям

Одностраничное веб-приложение: нейросеть решает домашнее задание **по фото** или **по тексту**.

## Возможности
- Поисковая строка для ввода задачи (например: `x² − 5x + 6 = 0`, «Скорость света?»).
- Загрузка фотографии задачи — текст на картинке распознаётся и подставляется к запросу.
- Решение по шагам с объяснением (локальная база: уравнения, деление, физика, история, геометрия).
- Тёмная и светлая тема с переключателем.
- Анимированный фон-нейросеть на Canvas (уважает `prefers-reduced-motion`).
- Полностью работает в браузере, фото не загружается на сервер.

## Запуск
Просто открой `index.html` в браузере. Сервер не нужен.

## Структура
- `index.html` — самостоятельное приложение (всё в одном файле), готовое для GitHub Pages.

## Как это работает
1. Сфотографируй или введи задачу.
2. Локальный OCR (Tesseract.js с CDN) распознаёт текст на фото.
3. Модель разбирает запрос и возвращает пошаговое решение из встроенной базы примеров.

> Демо-режим: ответы генерируются локально по шаблонам. Для живого вопроа-ответа подключите реальный ИИ-бэкенд.
